# 像素鲸语

![像素鲸语图标](res/drawable/ic_launcher.png)

一个原生 Android DeepSeek 聊天客户端。2.5 版更新为暖纸色聊天界面，并改进长对话、错误提示和历史会话管理。

这是独立开发的客户端，与 DeepSeek 官方无隶属关系。

## 功能

- 从左侧会话列表新建、搜索、置顶、重命名、删除或切换会话。每个会话的文字草稿独立保存在本机。
- 每个会话有一份可编辑的默认系统提示词，也可独立选择 DeepSeek Flash 快速问答、Flash 深度思考或 V4 Pro 深度思考。
- 流式显示回复，支持停止、分享单条消息和重新生成。重新生成失败时保留原回答。点历史消息的“编辑”可修改问题并在新分支发送，也可从消息菜单中直接创建分支。
- 有较早对话可整理且活跃上下文估算超过 256,000 token 时，应用会自动整理部分历史。手动压缩和遭遇服务端上下文或附件超限时，会保留最新一轮原文，历史和附件仍可查看。安全检查、参数、文档或账号错误会显示对应提示。生成摘要会调用 DeepSeek API 并消耗额度。
- 发送图片与文字一起提问。图片会在本机缩小、去除原始元数据并保存到应用私有空间；图片问答使用 DeepSeek Flash，V4 Pro 仅用于纯文本会话。
- 输入栏上方可为每个会话独立开启联网搜索和链接读取；搜索过程显示状态，回答显示可点开的来源卡片。联网工具仅支持 Flash，开启后使用 Pro 的会话会切换到 Flash。
- 可选择 PDF、Office、图片和常见文本等文档进行问答。文档先上传到 DeepSeek Files API 完成解析，文件 ID 保留在本机会话中以供后续轮次复用。文档上传与解析、联网问答可能产生 API 费用；上传到 DeepSeek 的文件由其服务保存，本地删除会话不会自动删除远端文件。
- 一条消息可附多张图片和多份文档，可一次多选，也可重复点“＋”添加。单次最多 20 张图片和 20 份文档。
- “会话工具”可将所有会话、提示词、摘要与附件导出为 ZIP，并从备份追加导入。备份不包含 API Key、跨会话记忆或远端文件 ID；导入后文档在首次再次使用时重新上传。ZIP 文件包含私密聊天内容，请自行保管。
- “远端文件管理”可查看当前 DeepSeek 账户最近 100 个文件并逐个删除。账户下其他客户端的文件也会显示；删除文件后本机会话会清除对应 ID，下次使用时尝试从本机副本重新上传。
- Flash 问答与上下文压缩启用 DeepSeek `safety_check: high`；流式拒答会替换已显示的临时内容。
- “会话设置 → 记忆与夜间做梦”中可开启跨会话记忆。可在聊天中说“请记住：…”，也能添加、编辑和删除记忆。开启后，保存的记忆随问答发给 DeepSeek，用于当前问题相关的背景。
- 夜间做梦单独开启。应用会将开启后新发送的少量文字摘录交给 DeepSeek Flash，整理自动记忆并保留手动记忆。系统安排在设备本地凌晨 2 点后联网运行，实际时间受系统调度影响，也可点“立即整理”。整理会消耗 DeepSeek API 额度。
- 支持基础 Markdown、可横向滚动的代码块与单独复制代码。长会话默认渲染最近 40 条消息，可按需加载更早内容，图片缩略图异步加载。

## 安装

从 [最新 Release](https://github.com/ATRI-KWAII/pixel-whale-deepseek-android/releases/latest) 下载 APK，复制到 Android 6.0 或更高版本的手机，打开文件并允许该来源安装应用。首次打开后点右上角“⋯”→“API Key 设置”，填写自己的 DeepSeek API Key。使用仓库发布的 APK 可覆盖安装旧版；旧版的单一聊天记录会迁移到“之前的聊天”会话。自行重新签名的 APK 无法直接覆盖安装。

## 隐私与网络

- 问答与摘要请求发往 `https://api.deepseek.com/chat/completions`，文档上传发往 `https://api.deepseek.com/files`。使用 DeepSeek 官方文档当前列出的 `deepseek-flash` 与 `deepseek-v4-pro` 模型。图片随当前会话的请求一起发送；应用不请求相册读取权限，附件选择由系统选择器完成。
- API Key 在 Android Keystore 中使用 AES-GCM 加密后存入应用私有空间，不写入 APK。
- 会话、系统提示词、草稿、聊天记录、图片副本和压缩摘要保存在应用私有空间。为接续联网思考，本机还会保存 DeepSeek 返回的思考字段。每次请求只携带当前会话的系统提示词、压缩摘要和未压缩的消息。删除或清空会话也会删除其中的图片副本。
- 卸载应用会删除本地数据；清除 Key 可在设置中完成。

## 构建

源代码使用 Android SDK 35 的命令行工具、JDK 17 以上和 PowerShell 构建。设置 `ANDROID_SDK_ROOT` 环境变量后运行 `./build.ps1`，或使用 `./build.ps1 -SdkRoot <SDK路径>`。APK 默认输出到项目的 `dist` 目录。构建脚本在本机生成开发签名；该密钥不提交到仓库。发布到应用商店前应改用自己的正式签名。
